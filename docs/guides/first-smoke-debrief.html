filemem-bench · first live baseline

What happened on the way to 0/33

A walkthrough of the eval harness we built, the first RTX 3070 + Ollama smoke run, what worked, and why every scorecard check failed.

01 · Intent

What we set out to do

  • Build a near-$0, open, reproducible test bench for filesystem-based LLM agent memory.
  • Run it first on local hardware (Ollama + RTX 3070), not cloud APIs.
  • Separate management (write/update memory) from search (read & answer).
  • Score with a deterministic pass/fail scorecard, not vibes.
  • Keep design notes private; ship the harness + suites publicly.

07 · Root cause — management

Organized store stayed empty

  • Almost every create / str_replace had path=None → harness rejected them
  • Model invented illegal tools: rm, update, check
  • Tried absolute Windows paths and mass deletes
  • Often called done without writing any facts

Consequence: drink, emergency contact, atlas deadline, Priya facts — none present for graders.

08 · Root cause — search

Answered without reading memory

  • Usually done on step 1 — no real browse of the store
  • Citations were placeholders: path.md, path/to document
  • Hallucinations (e.g. “John Doe” emergency contact) and generic knowledge
  • Even verbatim (chunks on disk) wasn’t used properly
  • Sometimes stuffed answer fields into view arguments

09 · Failure cascade

Why everything failed together

1
Manage cannot emit valid tool JSON with paths
2
Organized memory never materializes
3
Search skips exploration / fakes citations
4
Every fact_present, answer_match, citation check → fail

Fixing manage alone wouldn’t fully save the run — search also needs tool discipline.

10 · Verdict — right

What went right

Science / product

  • Clear unit under test (manage vs search)
  • Deterministic scorecard caught total protocol failure
  • Ledger + trajectories made root cause obvious
  • Mock path proves graders & suite are coherent

Engineering

  • Standalone public repo with clean author identity
  • Windows desktop path documented
  • Verbose runner / Ollama probe after silent-run pain
  • Design docs kept out of public tree

11 · Verdict — wrong / weak

What went wrong

Model / prompts

  • R1-distill 7B poor at strict JSON tools
  • Prompts too thin (no worked path examples)
  • format: json alone didn’t enforce schema
  • Zero score looks catastrophic; it’s informative

Process bumps

  • GitHub account / email attribution churn
  • Co-author trailers / force-push cleanup
  • Task Manager misread as “GPU idle”
  • Early silence made hangs hard to diagnose

12 · The real lesson

The bench worked. The agent didn’t.

A good eval separates infrastructure success from model competence. We can run, grade, and explain failure. We have not yet shown a live 7B that can maintain filesystem memory under this protocol.

13 · Next moves

Where to push next

  • Prompt hardening — few-shot create/view with real relative paths
  • Model swap — try a less “thinky”, more instruction-following 7B
  • Schema guardrails — reject/repair malformed tool calls earlier (optional)
  • Re-run smoke until manage writes a non-empty organized store
  • Only then scale to core and self-learning arms
