# Agent Memory Bench — Smoke v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a runnable `amb` package that validates the `smoke` suite, builds verbatim stores, runs manage/search via Ollama (or a mock LLM for tests), grades ledgers with deterministic scorecard checks, and writes a DD-04-compliant run ledger + `REPORT.md`.

**Architecture:** Python package `amb` with layered modules—suite loading/validation, harness (`memory_tool_v1`), agent loops (manage/search), ledger I/O, pure graders (`norm_v1` + families), and a Typer/argparse CLI. Fixtures live under `suites/smoke/`. Tests are CPU-only (mock LLM + negative store fixtures); live Ollama is optional for integration.

**Tech Stack:** Python 3.11+, pytest, PyYAML, httpx (Ollama HTTP), pathlib; Apache-2.0 destined. No LangChain required for v1.

**Specs:** AMB-DD-01…06 (Approved). Self-learning (DD-07) out of scope for this plan.

```python
# src/amb/norm.py
import re
import unicodedata

_WS = re.compile(r"\s+", re.UNICODE)

def norm_v1(text: str, *, for_answer: bool = False) -> str:
    if text is None:
        return ""
    s = text.encode("utf-8", errors="replace").decode("utf-8")
    s = unicodedata.normalize("NFKC", s)
    s = s.casefold()
    s = s.replace("\r\n", "\n").replace("\r", "\n")
    s = _WS.sub(" ", s).strip()
    if for_answer:
        s = s.strip(".,;:!?\"'")
    return s
```
